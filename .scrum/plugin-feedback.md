# plugin への改善提案

## Sprint 1
- 対象：`code-reviewing` と `security-reviewing` の判定書式
- 事象：環境の都合で実行できなかった検証（`-race`、`govulncheck`）を、判定書式で表す欄が無い。報告の末尾に毎回書かれるだけで、対処の対象にならなかった。
- 提案：`checks`（または `tests`）欄を「実行：<コマンドと結果>」「未実行：<コマンド>／理由」の2行構成にする。`sprint-execution` で、未実行が複数の PBI で続いたら改善 PBI の候補として記録する手順を足す。
- 事象：重要度の基準に「外部仕様に反する疑い（モックでは確かめられない）」「プロセス全体が落ちる経路」の扱いが無く、どちらも should として承認された。
- 提案：must の例に、この2つを加える。今回はチーム合意 T1-2 で先に試す。
