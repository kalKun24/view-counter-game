# Sprint 1 のデモ
## ゴール
PO が API キー無しでサーバーを起動し、検索ワードを送ると、タイトルにすべてのワードを含む動画の最大再生回数と動画タイトルが返ること、該当なしの場合とキャッシュの効き目を、curl で確かめられる。

## 動かし方
```
bash .scrum/demos/sprint-1/demo.sh
```
- 前提：Go、curl、python3 が使えること。所要時間は約 30 秒（場面 9 で 3 秒待つ）。
- モック（`USE_MOCK=1`）だけを使い、本物の YouTube Data API は呼ばない。curl の宛先は 127.0.0.1 の自分のサーバーだけである。
- 空いているポートを自動で選ぶので、台本の `localhost:8080` は実行時のポートに読み替える。
- 日本語や全角スペースは `curl -G --data-urlencode` で URL エンコードして送る。
- 最後に `go test ./...` を実行し、同時アクセス、エラーの非保存、上限での破棄、API キーのログ非出力を、対応するテスト名とともに示す。
- 動かすコードを変える場合は、第1引数にディレクトリを渡す。

## 台本
| # | PO の操作 | 期待する結果 | PBI |
|---|---|---|---|
| 1 | API キー無し、`USE_MOCK=1` も無しでサーバーを起動する。 | 起動に失敗する（終了コード 1、ログに `YOUTUBE_API_KEY is not set`）。 | #2 |
| 2 | `USE_MOCK=1` でサーバーを起動する。 | 起動ログに `youtube client: mock` が出る。 | #2 |
| 3 | `curl -G --data-urlencode 'q=猫 ピアノ' http://127.0.0.1:<port>/api/views` を実行する。 | `found:true`、再生回数、動画タイトルが返る。ログは `cache miss`。 | #1 |
| 4 | 3 のワードを、語順・全角スペース・大文字に変えて送る（`ピアノ 猫`、`猫　ピアノ`、`Cat Piano`、`cat　PIANO`）。 | 3 と同じ結果が返る（ラテン文字の組は、その組の中で同じ結果）。 | #1 |
| 5 | `q` を空にして送る。 | 400 と `invalid_query` が返る。 | #1 |
| 6 | `q=nomatch` を送る。 | `found:false` が返る。 | #1, #2 |
| 7 | `q=error` を送る。 | 502 と `upstream_error` の JSON が返り、API キーや上流の生の応答は含まれない。 | #1, #2 |
| 8 | 新しいワード `犬 ギター` を2回送る。 | ログに1回目は `cache miss`、2回目は `cache hit` が出る。 | #6 |
| 9 | `CACHE_TTL=2s` で起動し、送ってから3秒後にもう一度送る。 | 再び `cache miss` になる。 | #6 |
| 補足 | `go test ./...` を実行する。 | すべて ok。対応するテスト名が表示される。 | #1, #2, #6 |
